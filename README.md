# Reels Atölyesi

Fotoğraflarınızdan **yapay zekâ anlatımlı, sesli, Türkçe altyazılı** dikey (9:16) Instagram Reels / YouTube Shorts videosu üretir; ardından aynı sayfada **başlık, açıklama ve etiketleri** tek tıkla kopyalanacak şekilde verir.

Sunucusuz, tamamen tarayıcıda çalışır (GitHub Pages). Telefondan da açılır, video doğrudan telefona inebilir.

## Kullanım
1. https://aistudio.google.com/apikey adresinden ücretsiz Gemini API anahtarı alın, uygulamaya yapıştırın (yalnızca tarayıcınızda saklanır).
2. Görselleri ekleyin → **Anlatımı yaz** → metni isterseniz düzenleyin → **Sesi üret** → **Videoyu oluştur** → **İndir**.
3. **SEO metinlerini üret** → her alanın yanındaki **Kopyala** ile yapıştırın.

## Notlar
- Video süresi kadar gerçek zamanlı oluşturulur; sekmeyi ve ekranı açık tutun.
- Chrome/Android ve Safari MP4 üretir; Firefox WebM üretir (Instagram MP4 ister).
- Anahtarınızı Google tarafında “HTTP yönlendiren” kısıtıyla yalnızca bu sitenin adresine kısıtlamanız önerilir.
- Modeller: metin/görsel `gemini-2.5-flash`, ses `gemini-2.5-flash-preview-tts` (Ayarlardan değiştirilebilir).
